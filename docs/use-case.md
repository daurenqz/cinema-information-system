# Use Case сценарийлері

## UC-01 — Онлайн билет сатып алу
**Actor:** Клиент; қосымша актор — төлем провайдері.

**Бастапқы шарт:** Клиент жүйеге кірген, сеанс жарияланған.

**Негізгі сценарий:**
1. Клиент фильм мен сеансты таңдайды.
2. Жүйе баға мен бос орындарды көрсетеді.
3. Клиент бос орынды таңдайды.
4. Жүйе орынды 10 минутқа брондайды.
5. Клиент төлемді растайды.
6. Төлем провайдері нәтижені жібереді.
7. Жүйе төлем мен броньды тексереді.
8. Жүйе орынды сатылған деп белгілеп, QR-билет жасайды.

**Нәтиже:** Бір орынға бір билет тіркеледі.

## UC-02 — Кассада билет сату
**Actor:** Кассир.

1. Кассир фильм мен сеансты ашады.
2. Жүйе бос орындарды көрсетеді.
3. Кассир орынды таңдайды.
4. Жүйе орынды уақытша брондайды.
5. Кассир төлемді тіркейді.
6. Жүйе билетті қалыптастырады.

## UC-03 — QR-билетті тексеру
**Actor:** Билет бақылаушысы.

1. Бақылаушы QR-кодты сканерлейді.
2. Жүйе билет мәртебесі мен сеансты тексереді.
3. Жарамды билет қолданылды деп белгіленеді.
4. Қайта қолданылған билет қабылданбайды.

## UC-04 — Сеанстарды басқару
**Actor:** Әкімші.

1. Әкімші фильмді таңдайды.
2. Зал, күн, уақыт және бағаны енгізеді.
3. Жүйе уақыт қақтығысын тексереді.
4. Қате болмаса, сеанс сақталады.
